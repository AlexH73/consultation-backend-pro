# BackendPro – Consultation 🚀

This repository contains educational backend materials for **Consultation Group Cohort 59**.
The project is used during consultations to revisit core Java topics, practice concepts,
and build a solid backend foundation step by step.

---

## 📂 Project Structure

```
Consultation/
├── src/
│   ├── main/java/de/ait/
│   │   ├── unittests/ #Unit test examples
│   │   ├── faker/  #Data generation utilities
│   │   ├── exceptions/ #Custom exception handling
│   │   ├── streamapi/ #Stream API examples
│   │   └── ...
│   └── test/java/de/ait/
│       └── unittests/ #Unit test implementations
└── pom.xml #Maven configuration file
```

- **One project = one group**
- **Each package represents a consultation topic**
- Test classes are placed in `src/test`

---

## 🛠 Technologies & Tools

- **Java JDK 23** (programming language)

- **JUnit 5 (Jupiter)**

- Focus on understanding fundamentals
